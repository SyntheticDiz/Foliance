# Foliance working instructions

Read README.md and HANDOFF.md before changing the app. Work only in this project. Other applications and their user data must remain unchanged.

Foliance is a general-use document reader. Keep political branding, municipal assumptions, personal data, credentials, imported user settings, and legacy migration out of this project and its release artifacts. All bundled examples must be fictional. Never read another app’s Keychain or preference domain.

Keep sources and full passages accessible. AI interpretations are not verified facts. Do not transmit documents or make live AI requests during tests without explicit authorization.

Delegate bounded implementation tasks to GPT-6 Luna with exclusive file ownership; the main agent reviews and verifies integration. Subagents must not delegate.

For releases, keep version/build, Info.plist and patch notes consistent. Run meaningful tests, a release build, privacy/branding audits and native UI checks. Document signing, provisioning or App Store account requirements honestly; never call an ad-hoc build submission-ready.
