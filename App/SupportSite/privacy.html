PLAIN-LANGUAGE POLICY

Your documents.
Your choice.

Foliance keeps work files on your Mac. You choose on-device Apple Intelligence, your own OpenAI API key, or an eligible ChatGPT plan account. This policy explains each path.

01

Data in the app

Foliance reads PDFs that you choose. Document text, saved results, questions, notes, selected passages, recent-file bookmarks and work files are kept in Foliance’s local app container on your Mac. The app does not sync these files to a Foliance service.

Foliance has no Foliance-managed account system, advertising, tracking or analytics SDK. There is no developer backend receiving your PDFs. Apple may separately handle App Store downloads, purchases and system diagnostics under its own policies.

02

AI processing

On device Apple Intelligence

The default analysis option uses Apple’s on-device Foundation Models. It requires compatible Apple silicon, macOS 26 or later, Apple Intelligence enabled and a downloaded English model. Document content stays on your Mac for this option. Apple may need a connection to download its system model.

Optional OpenAI API key

If you select the API option, provide your own key and grant document-sharing consent. When you explicitly start analysis, Foliance sends the extracted document text and passages needed for the task, relevant reference-document text and comparison criteria, your reading goal and questions directly to OpenAI. API use is billed to your OpenAI API account, separately from Foliance and ChatGPT subscriptions. Access depends on your API account.

Your API key is stored in Foliance’s non-synchronizing Keychain entry. It is not saved in ordinary preferences, work files, exports or this website. You can remove the key and revoke consent in Settings.

Optional ChatGPT plan

Continue with ChatGPT opens OpenAI’s authorization page in your system browser. You authorize identity and plan-usage permissions yourself. Foliance receives a verified account identifier, email, an issued client-registration identifier and OAuth tokens, then retrieves that account’s available model catalog. OpenAI associates the registration with the authorized account and workspace. Eligible analysis may use that account’s ChatGPT plan usage or credits, subject to account eligibility and usage limits. It does not grant Foliance access to your ChatGPT conversations.

Plan credentials and saved account registrations are held in Foliance’s separate, non-synchronizing Keychain storage. Access tokens renew automatically while the OpenAI connection remains renewable. Signing out attempts to revoke the session and clears local tokens; a revoked or expired session may require sign-in again. A temporary sign-in callback listens only on 127.0.0.1 on this Mac. Foliance stores a stable, opaque installation host identifier in its separate preferences and sends it during authorization so OpenAI can associate plan usage with this installation. When reauthorizing, Foliance may also send the saved email and prior ID token as account-selection hints. OpenAI does not specify retention periods for the host identifier or these hints. Credentials are not copied from another app or included in work files, exports or source code. You can sign out and manage app access in ChatGPT settings.

ChatGPT sign-in is not consent to send your documents. You separately approve document sharing in Foliance before a task is sent. The API-key and ChatGPT-plan options use distinct access and billing paths; Foliance never silently switches between them.

OpenAI data handling

For API requests, Foliance asks OpenAI not to store Responses for later retrieval. This does not guarantee zero retention: prompts and responses may be retained in abuse-monitoring logs under OpenAI’s API data policies. ChatGPT plan use is subject to the applicable OpenAI account and service terms. Review the terms for the option you choose before sending confidential material.

All AI output can be wrong or incomplete. A matching quotation confirms where text appears, not that an interpretation is correct. Check important claims against the original document.

03

Saved work and exports

You choose where to save exported PDFs and portable .foliance work files. A work file can contain the original PDF, an optional reference document, analysis, reading goal, selected profile, notes and annotations. Anyone who receives it may be able to read those contents; share it only with intended recipients.

Deleting a recent-file shortcut does not delete the original PDF. Reading, local search and available saved results work offline.

04

This support website

The public site is hosted by GitHub Pages. GitHub may process visitor request information and service logs under its own terms. That hosting activity is separate from the Foliance app’s local files and AI processing. The site has no analytics, advertising or tracking scripts.

If you follow a GitHub Issues link, information you submit there is handled by GitHub and the project issue tracker. Issues may be public. Do not include private PDFs, document text, personal information, API keys or sign-in tokens.

When you deliberately open another external link, the linked website receives the browser request under its own privacy policy. Foliance does not attach your PDF to that request.

05

Your choices

  • Choose which documents to open and where exported files are saved.
  • Use Apple Intelligence locally, or separately enable an OpenAI option and its consent.
  • Revoke document-sharing consent, remove an API key, or sign out of a ChatGPT plan account in Foliance Settings.
  • Use reading, local search and saved work without starting a cloud request.

For help, visit Foliance Support. Release status: preparing for the first release; no download is available yet.

In brief: App documents stay on your Mac unless you choose cloud analysis and consent. ChatGPT sign-in stores account credentials locally; it is separate from consent to send document content. GitHub Pages request logs are separate from app processing.
