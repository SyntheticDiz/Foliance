01Why is AI analysis unavailable?

Apple Intelligence: use a compatible Apple silicon Mac with macOS 26 or later. Turn on Apple Intelligence and wait for its English model to download.

OpenAI API: save your own API key, choose a model ID available to your API account, and grant document-sharing consent. API access and billing are separate from a ChatGPT subscription.

ChatGPT plan: continue with ChatGPT in your browser, select the saved account you want to use, then choose a model currently offered in that account’s catalog. Usage depends on account eligibility and limits. Consent to send task content is still required.

Foliance does not switch providers or billing methods silently. You can still read, search and review saved results when analysis cannot run.

02What is the difference between the two OpenAI options?

The OpenAI API option uses your API key and your API account’s separate billing. You choose a model ID that your API account can access.

The ChatGPT plan option signs in to an eligible ChatGPT account and uses its available plan usage or credits. Foliance shows models returned by that account; access and limits can change. Signing in does not give Foliance access to your ChatGPT conversations.

Both options require separate consent before document text is sent. See the privacy details.

03Why can’t Foliance read my scanned PDF?

A scan may contain only page images, with no selectable text. Foliance needs a text layer to search, quote and link back to a passage.

Run OCR with a tool you trust, then open the searchable PDF. Check recognized text against the original scan, especially figures, dates and tables. OCR can make mistakes.

04How should I check a finding?

Open the source link and read the full surrounding passage in the PDF. Verify numbers, dates, conditions, exceptions and who said what.

A matching quotation helps confirm where a passage came from; it does not prove that an interpretation is correct. Treat AI output as a reading aid and rely on the original document when something is uncertain.

05Where are notes and saved work kept?

Foliance stores its working data and recent-file bookmarks in its own local app container. You choose where to save exported PDFs and portable .foliance work files.

A work file can include the original PDF, reference document, results, reading goal, notes and selected passages. Anyone with the file may be able to read that information, so share it only with intended recipients. Removing a recent-file entry does not delete the original PDF.

06What goes into an export?

Choose the sections and scope in the export window, inspect the preview and filename, then select a save location. Depending on your choices, a PDF may contain source passages, your notes or saved excerpts.

Foliance does not upload exported files. Review the preview before sharing a copy.

07Does Foliance need the internet?

Reading, local search and saved work are available offline. Apple may need a connection to download its on-device model. OpenAI API and ChatGPT plan analysis need an internet connection for their requests or sign-in.

For either cloud option, Foliance asks for document-sharing consent before sending task content. Opening an external website link sends a browser request to that site under its own policy.
