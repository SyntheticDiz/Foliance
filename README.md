# Foliance

A free, open-source macOS PDF reader for source-linked analysis, notes and export.

- [Application source](App/)
- [Build instructions and requirements](App/README.md)
- [Public website](https://syntheticdiz.github.io/Foliance/)
- [Support](https://syntheticdiz.github.io/Foliance/support.html)
- [Privacy](https://syntheticdiz.github.io/Foliance/privacy.html)
- [Website source](App/SupportSite/)

Foliance requires macOS 26 or later. Apple Intelligence is the local default; optional OpenAI API-key and eligible ChatGPT-plan connections use each user's own account, explicit document-sharing consent and separate billing paths. The interface and tutorial are English; original document quotations remain unchanged.

The first App Store release is being prepared. No App Store download is available yet. To build locally, clone this repository, change to `App/`, and follow its README. The public export includes focused offline tests with fictional data; private research probes and local signing settings are excluded.

MIT License. Third-party licenses are retained in `App/ThirdPartyLicenses/`. Never commit credentials, private documents or signing material.
