FOLIANCE HELP

A clear answer,
close to the work.

Start with the issue you're seeing. These notes cover the common steps for reading, checking, and keeping a document.

Foliance is preparing for its first release.

01Why is AI analysis unavailable?

For Apple Intelligence, use a compatible Apple silicon Mac running macOS 26 or later, enable Apple Intelligence, and let its English model finish downloading. For OpenAI API, add your own API key, select an available model, and grant document-sharing consent in Foliance Settings.

If OpenAI returns an access or quota error, check the key’s permissions, model access, and API billing. Foliance does not switch providers silently. You can still read and search available PDF text without starting AI analysis.

02Why can't Foliance read my scanned PDF?

A scan is usually an image of a page, not selectable text. Foliance needs a readable text layer to search, quote, and link findings back to the document.

Run OCR with a tool you trust, then open the resulting searchable PDF. Check recognized text against the original scan, especially figures, dates, and tables.

03How should I check an AI finding?

Open the linked source passage and read the surrounding paragraph in the PDF. Confirm that amounts, dates, conditions, exceptions, and who said what match the document.

AI interpretations are reading aids, not verified facts. If a quote or connection cannot be confirmed, rely on the original text and keep the point marked for review.

04Where is my work saved?

Foliance keeps document text, summaries, questions, notes, selected passages, recent-file bookmarks, and saved work in its own local app container on your Mac.

You choose where to save exported PDFs and portable .foliance work files. A work file contains the original PDF plus its analysis and annotations, so share it only with people who should receive that material.

05What goes into an export?

Choose the sections and scope in the export window, review the preview and filename, then select where to save the PDF. An export may include source passages, your notes, or selected excerpts, depending on your choices.

Read the preview before sharing. Exported files are copies you control; Foliance does not upload them.

06Does Foliance need an internet connection?

Reading, local search, and reviewing saved work work offline. Apple may need a connection to download its on-device model. OpenAI API needs an internet connection for each request. Opening a link in your browser sends a request to that website.

With Apple Intelligence, document content stays on your Mac. If you choose OpenAI API and grant consent, task content is sent directly to OpenAI using your own key. API usage is billed to your OpenAI account. You can remove the key or revoke consent in Settings.
