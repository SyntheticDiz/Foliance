# Foliance

The public website, support information and privacy policy for Foliance, a general-use Mac PDF reader.

- [Website](https://syntheticdiz.github.io/Foliance/)
- [Support](https://syntheticdiz.github.io/Foliance/support.html)
- [Privacy](https://syntheticdiz.github.io/Foliance/privacy.html)

Foliance is preparing for its first release. This repository contains the static public site.

Report app issues using this repository’s Issues tab. Please do not include private PDFs, credentials, or personal data.
